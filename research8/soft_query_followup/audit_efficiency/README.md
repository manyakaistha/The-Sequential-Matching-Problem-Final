# Audit efficiency recovery

All 2,880 simulation cells finished. The original single-process full audit was stopped after roughly35minutes and188cells because the public-history membership checker rebuilt the same canonical sets for every record. No simulation, commit, archive, frozen registration, v2/v3 source or AGENTS.md was changed. Its unfinished partial checks had no durable certificates and are not reused.

fast_audit.py pins the original audit sources, copies the stream checker with exactly one cached-lookup transformation, and keeps every other statement unchanged. It calls the original v3 complete-grid auditor with the optimized stream function in an isolated process. A same-cell benchmark measured7.363seconds versus1.554seconds with identical action digest; both checkers rejected corrupted request evidence identically. The full v3 suite passed51tests and10subtests with the optimized checker installed. Independent review found no blocking issue.

Full independent checks remain necessary to certify public outcomes, action legality, temporal observation validity, original/continuation attribution and common-world pairing. Compression hash checks alone cannot establish those facts. The optimization changes computation cost, not the criteria for passing. Materialization remains one512MiB bounded extraction, with a separate2GiB process RSS guard. Every verified cell gets an immutable checkpoint binding both registrations, source/auditor hashes, original commit bytes and physically rehashed archive/catalog bytes. Resume reuses only fully bound checkpoints. Final proof checks the complete fixed grid and final commit inventory.

The active audit log is fast_audit.log; launch.json records its PID/arguments. full_grid_proof.json appears only after all checks pass. Do not start another auditor while it is running. To resume after a stopped process, use the exact command in launch.json; existing checkpoints are verified, not blindly trusted. Abandoned auditor extraction duplicates may be removed only after its process stops and while holding the output/.audit_tmp/.materialization.lock. Archives and commits are never removed.

provisional_results.json provides the registered96-seed-cluster statistics and seven Holm-adjusted contrasts now, without another audit or raw-log scan. It is explicitly provisional and not certified. Mechanism diagnostics are deferred. Do not call it audited, fresh confirmation, or evidence of a winning policy. Do not run v2/analysis.py directly on this archived continuation: it reruns a raw-only audit and expects deleted raw duplicates. A final report must consume the exact-input-bound full proof/checkpoints rather than repeat the full public-event audit.
