# Predictive and model-light research agenda

Status: source-based proposals, 14 October 2026. Owner: `/root/model_research`; independent reviewer: `/root/w2_critic`; integrating reviewer: root. This work read source, plans, provenance and published summaries only. It ran no generator, episode, replay, fit, or holdout-dependent selection. No realized private world was read. Only this file is owned by this work order. The 180 CPU-second allowance is a ceiling; all executed commands were bounded reads or document editing, not a numerical research job.

## Recommendation

Run two paths in parallel conceptually, with one shared experiment ledger: a **small public-feature policy family optimized on complete episodes**, and a **public-data model ladder that earns complexity only when its information changes useful actions**. The first path can investigate reward without waiting for a complete joint transition asset. The second supplies the coherent reward, occupancy and feedback beliefs needed by B1 and principled acquisition. Neither has demonstrated superiority over G/Q6/P.

The next cheap work should be extracting a public opportunity inventory and building an auditable linear scorer/local repair controller. It should answer whether quality-driven alternative matchings, informative returners, soft-question displacement and reservation opportunities actually occur. A model that predicts well only for actors already paused, or only scales all edges equally, has little allocation value. Reimplementing the earlier population scorer with a larger learner is a low priority: its prior coefficients and several earlier shrinkage/throughput controls already have unfavorable or inconclusive evidence. A calibrated joint model is scientifically attractive but currently a large admission dependency, not an established shortcut to a win.

## Public feature, label and censoring schema

Export three linked immutable tables, with a separately stored assignment-time request prefix. Raw logging can contain host evaluation metadata, but the fitting export must pass a field allowlist before any learner reads it. Seed/family belong only in grouping/reporting metadata outside the feature matrix. Asset manifests bind source/log/export/split/recipe hashes; a signature proves identity, not calibration.

| Table | Required public content | Target and interpretation |
|---|---|---|
| Decision snapshot | Episode group, day/phase, exact sanitized request, public history prefix, source/config/asset hash, all current legal edges, chosen complete ask/matching, predictions made before action | Coverage/action-change denominators; no outcomes for unassigned edges |
| Actor trial | Introduction+actor+stage key, assignment/observed/occurred days, partner public snapshot, released Yes/No/no-response, stage eligibility, maturity/censor status | Response flag and conditional responding Yes separated; a first-Yes surrogate can deliberately combine No/no-response but must name that target |
| Dyad outcome/trajectory | Both first outcomes, date outcome and lag, second outcomes/lags, pause, daily public availability sequence after assignment, administrative end day | Nested unconditional funnel labels; qualified eventual reward; return/observation trajectories and unresolved censoring |

Initial scorer features should be small and explicit:

1. For each soft field, observed equality/difference, both/one/neither observed, statuses and disclosure ages. Do not substitute `1/cardinality` as a learned missing value. Use train-estimated distributions when a probability model needs integration; include missing indicators in a direct regression. Preserve directed known values where an answer model needs them. A source-motivated four-field model and all-seven-field model are explicit competing configurations, with coefficients fitted or policy-tuned on training only.
2. Actor resolved first response, conditional Yes, and eligible second response/Yes counts with trial count and strong shrinkage. Use order-invariant pair combinations (sum/min/max/product) rather than input endpoint order. Response and willingness are different latent quantities. Do not carry a past dyad shock to a new partner.
3. Public graph summaries: unused feasible degree, unresolved possible degree, component size, highest/second-best alternative score, query eligibility, verified status, age since arrival. These primarily predict opportunity/continuation; graph association with success in selected logs is not evidence of a demographic or psychological mechanism.
4. Day and remaining action horizon through generic smooth/coarse features. No literal family detector or embedded hidden change day. Age/gender/zone can define eligibility and coverage slices; success-prediction effects enter only if a predeclared train-only analysis supports them. Opaque IDs are joins/ties, never predictive tokens.

Store five nested unconditional dyad outcomes: both first respond, mutual recorded Yes, date happens, both second Yes/pause, qualified reward. Also store both second respond separately. Score conditional stages only on eligible mature rows. For a qualifying-date funnel, the chain rule

`q(H) = P(mutual Yes|H) × P(date happens and lag≤30|mutual Yes,H) × P(both second Yes with both lag≤3|qualifying date,mutual Yes,H)`

is exact when each conditional factor uses the same conditioning and includes joint dyad outcomes. Multiplying separately fitted marginal actor probabilities does not automatically implement it. A direct composite ridge model is a mandatory competing predictor; using public mean/equality features in that empirical regression is legitimate as a regression, but not an exact latent-mechanism integration claim.

Explicit first no-response is observed at its deadline; absence before then is pending. Second no-response is a mature nonresponse only when released or its supported collection window closes. Structurally absent seconds after rejection/cancellation are not actor second-response failures. An unconditional terminal label can become zero once a decisive observed failure establishes impossibility; otherwise retain censoring until resolution. Administrative loss of follow-up is never silently zero. Deduplicate cumulative feedback by introduction+actor+stage; pause summarizes the second outcomes and must not supply a second independent likelihood factor.

## Likelihoods and selection that must be correct

A coherent latent ladder uses public-fitted persistent actor response/willingness types and one fresh dyad effect. For response propensity `r_i`, public first/eligible-second response indicators contribute their joint product conditional on `r_i`; an explicit response flag is not a willingness observation. Where the same `r_i` governs two eligible response stages, terminal expectations involve its second moment, not its mean squared. If a finite type model is used, learn type probabilities/locations from the registered public training partition rather than copying simulator bounds.

For each historical dyad, integrate the shared effect once over both first outcomes and observed late-stage outcomes. Reciprocal first Yes selects favorable dyad effects; later second feedback is conditioned on that selection. A past first Yes plus second No can change different actor/shock quantities, not merely add independent Bernoulli observations. Joint first-response categories must sum to one. Separate actor and dyad uncertainty; two edges touching an actor reuse its latent draw, while different new introductions get separate dyad draws. Query revelation and downstream hypothetical matching reuse the same profile draw.

Pending return inference requires `P(released feedback prefix, public availability prefix|H at assignment)`, with latent state integration. Not seeing a date by age a can update a return law only when the likelihood integrates rejection, response delay, possible date/cancellation, pause and exit. Do not learn an unconditional mean busy duration on completed fast returns and apply it to pending cases. A never-return trajectory mixes exit, retirement and administrative censoring; public observations alone may not identify a separate exit hazard. When identifiability is inadequate, fit the probability of **observable usable return** or sensitivity bands, rather than claim to have recovered actual exits.

Selection hazards are substantial:

* G/Q6/P choose which edges obtain labels. Scores on those selected rows do not establish correctness for all alternatives. Rows from different policies are different prediction cohorts; compare candidate predictors on identical snapshots within each collector and report transport separately.
* Later stages require earlier success. Training a second-stage model on all introductions mistakes structural absence for failure. Complete positive outcomes pause actors, so future available actors are survivors. Evaluate personalization at future legal opportunities, not just on historical respondents.
* Query answers are selected by the querying policy. Fit answer/disclosure models with ask policy, pre-ask status and query opportunity context; initial complete profiles and actively asked profiles are distinct cohorts. Preserve correlations within actor hard bundles and shared actor profiles across edges. Existing deterministic logs generally have null action propensities: they cannot supply unsupported IPS/DR policy-value estimates.
* Source audit suggests demographics/unrelated fields do not contain a designed unconditional latent-success mechanism. Flexible demographics, embeddings and missingness clusters can learn selection artifacts. Public data can support useful conditional associations, but they need changed-policy validation and cannot be called recovered private preferences.

## Data availability and a staged collection plan

Old public assignment snapshots and full-follow-up events exist under the R3 prospective contract; [`research3/PROSPECTIVE_DATA_CONTRACT.md`](../../research3/PROSPECTIVE_DATA_CONTRACT.md) identifies their separation from host oracles. Existing stored auxiliary `prediction` values are inherited diagnostic forecasts, not every candidate's score. Recompute named models from the historical request prefix; never overwrite snapshot fields with later answers. Archived JSON/TAR and R7 codec trajectories need a audited public-only extraction layer, verified round trips and explicit reuse registry before fitting. Do not assume every historical artifact is already a clean training table. No private oracle output, world regeneration or latent-probability labels enter the export.

A proposed sequence, to be frozen by the director before execution:

1. **Inventory without fits:** count mature labels, eligible returners with two or more trials, informative second histories on currently usable actors, missing useful soft fields, slack budgets, query-induced graph changes, score gaps between legal complete matchings, and reservation triggers. Define denominators separately: actor-days, feasible-edge-days, distinct available actors and actual assignment trials. Repeated edges/days are not independent sample size. Reuse designated development records only; do not mine future confirmation for gates.
2. **Small public collector if the export is inadequate:** prospective three behavior arms G, unchanged Q6, and one declared bounded randomized legal score-greedy/menu collector, as adopted in the director REPORT. Preserve unchanged P as a reward reference; it is not an additional adopted E1 collector. Randomize among whole feasible action templates and log their actual conditional probabilities and RNG recipe. This covers a limited menu, not every matching; do not claim full off-policy support. Anonymous future profiles are estimated from all deduplicated arrived members and their public missingness, not the available-pool count change. Old records may support this stage, but all examined worlds stay development forever.
3. **Director-adopted proposed cap:**32 training seed groups plus16 validation groups, all six families, three collectors =864 cells, each60+40 days. This is a proposal, not an executed batch or power guarantee. A four-collector/1,152-cell alternative is not adopted. All same-seed families/collectors stay in the same partition; validation actors/worlds are disjoint. Forecast storage/CPU with actual logger and candidate costs before freezing. If rare-stage counts fail, simplify or defer; do not automatically append seeds. R7's much larger unexecuted P2 allocation should not be inherited wholesale.
4. **Fit a tiny ladder:** global smoothed composite rate; direct ridge composite; separated response/conditional funnel model; finite joint actor model only after reusable-history counts justify it. Use at most three model families and a shared finite fit ledger. Start with one primary ridge penalty and one shrinkage choice; exploratory alternatives consume the budget. Coarse monotone calibration only if validation support permits; rare terminal isotonic bins can be unstable. Fit parameters on training, tune by whole-world inner folds, select/calibrate on registered validation, then freeze before new reward screening.
5. **Admission:** compare on identical mature held-out assignments using world-balanced log loss/Brier, calibration-in-the-large, frozen reliability bins/support, and collector transport slices. Report rare-positive counts and repeat-opportunity coverage. Interval widths, effect margins and practical gates must be chosen before outcomes; a permissive terminal absolute calibration threshold can admit a near-constant rare-event model. Require useful action differences as a separate gate. Probability loss improvement is neither a reward win nor a necessary condition for every model-light policy.

Do not fit an arbitrary large survival/mixture model merely to satisfy every B1 asset field. First estimate reward and return separately, test their joint relationship, then construct the joint emission law. Strong response-stage counts cannot substitute for second-stage or qualified-event counts. An asset with insufficient support for a rare-stage personalized claim can shrink that stage globally and explicitly narrow its claims.

## Ranked experiments and falsifiers

| Priority | Candidate and bounded change | Own parents and decisive failure |
|---|---|---|
| 1 | Low-dimensional score/local repair with FIFO or Q6 fixed | Same scorer score-greedy and G/Q6/P references; reject if changed full-match actions/score gaps are rare or fresh reward advantage fails |
| 2 | Finite complete-episode policy search described below | Fixed seed schedule/finite configurations, controls for score/query/reservation; reject training winner instability or fresh own-parent reward failure |
| 3 | Public response/first-Yes shrinkage, then direct composite ridge | Same static score and history-off; reject if informative actors are paused/no-unused-partner, coverage is small or changed-policy losses/reward fail |
| 4 | Controller-consistent soft/hard query templates, before Monte Carlo VOI | Identical post-answer allocator with FIFO/Q6 and no-soft; reject displacement harm, unsupported answer beliefs or no useful complete matching changes |
| 5 | Occupancy-aware renewal value with public usable-return law | Same quality/controller with continuation off, ratio and time-blind controls; reject last-day behavior, joint-opportunity double counting, tail/exit sensitivity or reward loss |
| 6 | Joint finite actor/dyad posterior and B1 emission kernel | Direct composite and response-only; reject likelihood inconsistency, off-support calibration, approximation/runtime failure or insufficient supported planning coverage |

**Soft-score repair and simpler allocation.** First freeze a compact symmetric linear score from public features, or explicitly retain an existing P ranking weight. Construct ordinary descending-score greedy matching, then at most two deterministic passes/20,000 probes over additions and one/two-edge alternating exchanges; preserve legality and unused dyads. Require score improvement over the complete parent action, with deterministic tie retention. Compare to unrestricted general-graph maximum weight offline/in supported bounded components. Weighted general-graph allocation must handle odd cycles; Hungarian is unjustified. R7 A1 already supplies a failed/inconclusive precedent, so a new repair needs a distinct score/computation or mechanism hypothesis, not a renamed A1 rerun. Local repair saves inference cost and supplies a direct whole-action margin; score gain remains surrogate evidence.

**Day59 control.** With admitted conditional calibrated qualified-eventual probabilities, maximizing `sum q_e(H)` over legal matchings is the correct final-day expected-reward objective, because no future assignments remain and expected reward is additive. It needs no return/exit model and includes eventual follow-up reward. Run this clean control on a frozen designated development cohort; compare estimated objective gap and actual fully followed reward separately. G is already maximal, so adding unmatched-unmatched pairs is not generic G headroom. A day59 weighted matching can exchange edges; with an uncalibrated linear score it is only a ranking-weight experiment, not an oracle or bound. Node opportunity prices vanish there; `q/duration` has no horizon rationale. Current-day waiting remains an option only in earlier stages.

**Query templates.** Before a full categorical VOI model, compare a few explicit same-controller packages: unchanged parent hard asks; three hard bundles plus three goal/pace/conversation questions on high-alternative-degree verified actors; and hard-first completion with only genuinely slack units used for soft asks. The3+3 package costs12 and can deliberately displace one hard bundle; do not call those units free or assume queried features are always unknown. Fill/skip rules must be deterministic and freeze duplicate/decline handling. A soft action can affect many incident scores but affects no hard legality. Control all-four-hard against mixed packages, and record budget opportunity frequency, revealed fields, changed edge scores, changed complete matching, later assignment sequence and reward. Any ranking of useful soft fields must come from training/whole-episode search or be an explicitly source-motivated hypothesis, not embedded generator weights.

When graduating to stochastic query evaluation, retain <=8 hard candidates/<=4 soft actions and <=32 complete packages initially, include exact parent batches, and sample <=16 joint actor profiles per package with a separate16-draw winner-parent check. Deploy exactly the evaluator's frozen post-answer controller. These are proposed work caps, not confidence bounds for model bias or measured timing. Public categorical answer models must preserve hard correlations and declines. A cheap deterministic optimistic graph query chooser is a useful comparator but Q1 versus Q6 has already been examined; it should not consume another slot without a new falsifiable distinction.

**Renewal values.** Prefer a time-dependent probability of another usable introduction before59 and opportunity value conditional on return over `reward/mean busy duration`. Cheap edge adjustment can use `q_e - E[foregone feasible alternatives during joint occupancy]`, where the occupancy law distinguishes ordinary return, cancellation occupancy and positive pause. It is an approximation: one future edge shared by two endpoints must not be charged twice, and actor-additive prices cancel between matchings covering the same actor set. Evaluate whole-action residuals or unique future opportunities in a small closed region. Any horizon penalty shrinks to zero at59. Return labels come from observed availability/feedback, not actual busy timers. Fail if twelve versus twenty-four-day tail assumptions, alternative exit/return bands or a nonseparable toy witness reverse too many switches. B1's known day13 falsifier cannot be repaired merely by claiming calibrated short-run return predictions.

**Uncertainty and calibration.** Prefer uncertainty over a complete matching advantage to per-edge lower-confidence scores. Use a small world-bootstrap model ensemble or posterior draws, including shared actor uncertainty, and switch only when a fixed model-margin rule supports the parent difference. Ensemble unanimity is model robustness, not a certified improvement. With sparse positives, an eight-model ensemble can be eight versions of the same misspecification and consumes eight fits; initially a single shrinkage model plus a fixed sensitivity envelope is cheaper. Report gate rejection/firing and usable opportunity denominators. Calibration can improve probabilities without changing matching; measure that invariance before spending policy episodes.

## Competing path: finite direct policy optimization

The model-light path treats score/query/reservation coefficients as policy parameters rather than probabilities. It optimizes actual complete-episode eventual qualified reward on designated training worlds and avoids needing the full B1 joint asset. This is legitimate black-box policy search with public inference features; it is not an offline causal estimate from selected assignment logs and does not inherit B1's correctness certificate.

A deliberately small family has four groups: three/four soft-equality weights with missingness indicators; one strongly shrunk public first-Yes history multiplier (including zero history); one reservation strength times remaining-horizon and public alternative-opportunity summaries; and a choice among two frozen hard/soft query templates. Keep dimension roughly6–8, fix score normalization, tie rules and allocator, and include the unmodified parent parameter values. Reserve by comparing complete actions/deletion templates; avoid interpreting an actor-additive penalty as a ranking gain for identical covered actors. Any reservation turns off at59. No tuning of ID salts.

The director-adopted proposed finite recipe is at most8 total parameter configurations generated once by a declared low-discrepancy/random draw, counting the unmodified parent within that cap, on32 training seed clusters across six families (at most1,536 cells). An earlier12-configuration alternative is not adopted. All draws and failed attempts count; no adaptive extension after an attractive result. Use world-group inner train checks to eliminate obvious brittleness, then freeze at most two mechanism families before fresh validation/screening, as adopted by the director REPORT. A smaller four-configuration ablation (score only; score+repair; score+repair+querymix; score+repair+reservation) may be preferable to8 random configurations if baseline rare-reward noise is high. The director must pick one recipe before execution; this is a competing proposal, not permission to try both and select afterward.

Pair policies on all six same-seed families and optimize equal-family episode reward, with coverage/validity constraints fixed beforehand. Changed dyad/day actions change hashed outcome streams: common worlds reduce some variation but do not hold every downstream draw fixed. Optimize neither acceptance counts nor an internal model value as a substitute for primary reward. Search winners are upward biased; training reward estimates cannot support a win claim. Whole-episode held-out own-parent/control evaluation, finite multiplicity accounting and untouched confirmation remain necessary. Retain complete controls for the two finalists. The director proposes at most8 total arms for fresh selection/replication, including G/Q6/P and every necessary parent; reduce entrants rather than discard controls. Earlier R7's12-arm cap is not a target for this new program.

This path is attractive because inference stays linear/bounded and cannot leak a fitted future schedule. Its weakness is sample inefficiency: rare terminal outcomes make dozens of coefficient comparisons mostly a noisy tournament, and a narrow policy family may miss coupled planning. Require stable broad parameter effects and predeclared mechanism changes, not a single salt/config winner. The complete-episode search and model-training paths share data/compute budgets and must not reuse their validation sets as independent confirmation. An inability to beat G/Q6/P after a fixed search is a useful negative result; it does not prove global optimality.

## Runtime and stop conditions

For<=200 members, at most19,900 candidate dyads exist. Compact linear scoring, one history aggregation pass, greedy sorting and bounded repair are plausible first targets for total cold-process invocation<1s; only measured public workload profiling can establish the target. W2's fast G fallback timing does not profile active B1. Cap immutable model assets at4 MiB for initial linear/categorical work, explicit public memory well below1 MiB, and store aggregate older actor counts rather than raw duplicate histories.

Do not integrate16 actor types per endpoint times32 shocks over all19,900 edges in ordinary Python and assume sub-second performance: that is roughly163 million latent combinations before history/feedback/serialization. The richer posterior belongs first in offline calibration or a supported<=6-actor region, with cached bounded feature/history signatures and approximation comparisons. B1 has explicit node/support/transition limits, but the richer feedback kernel can exceed them rapidly; overflow must discard the whole action comparison and retain the validated parent, never use a partial optimistic value.

Stop a route when (a) data support is below frozen rare-stage/usable-history gates, (b) likelihood/observation isolation fails, (c) meaningful complete actions almost never change, (d) held-out approximation/tail tests fail, (e) real resource limits fail, or (f) fresh actual reward versus required parents fails. Simplification is a new explicitly scoped candidate with a fresh freeze, not relabeling an unsupported personalized/full-planning model as admitted. The main scientific question is whether public information changes the right complete decisions often enough to produce repeatable qualified reward; predictor complexity alone cannot answer it.
