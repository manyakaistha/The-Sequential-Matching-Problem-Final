This directory prepares one fixed replication of the unchanged round-four
population_control policy against shipped greedy. It does not contain a new
policy or a completed experiment. Results/research5/design.json binds the source,
registry, exact seeds, power assumptions and prior manifest before evaluation.

- 430 independent seeds ×6 families ×2 policies =5160 episodes.
- Planning gain +.05 MSMI/100, SD .26; about90% model power before10% inflation.

- Three research workers; full logging adds unmeasured time/storage. Launch requires200GB free.
- No new worlds are generated by preparation/preflight.

From repository root:

```sh

```

To execute the entire registered test (not run during preparation):

This refuses duplicate/partial outputs, validates frozen hashes, checks free disk,
records actual compute, runs full60+40-day episodes, then analyzes only the complete
valid zero-fallback grid. Never run `prepare` again or edit frozen sources after
registration. Scientific success is uncertain; a nonsignificant result closes this
fixed test without extending its sample.

sensitivity, scenario results, resource summaries and failure eligibility.

reverification, raw archive verification and written review before a final claim.

preservation are checked without modifying any completed study.
