# Development repository

This repository preserves the original project history plus policy experiments, research rounds 1–6, round-seven plans, reports, dependencies, and the immutable research7a/research7b portable handoff snapshots. Round seven remains planning only; publishing these files does not validate scientific claims or authorize new experiments. Read each round’s reviews, limitations and reproduction instructions before using its results.

## Local evidence

Compact research result files are versioned. Raw trace directories, execution attempt/commit stores, event streams, raw tar archives and generated container contexts remain local. `LOCAL_RESEARCH_ARTIFACTS.json` inventories excluded artifacts from research rounds 3–6; older research/extended raw tar archives are also excluded by `.gitignore`. The inventory records paths and sizes where available, not integrity verification. Existing research manifests and archive indexes describe provenance. Full independent reproduction or historical seed audits may require those external archives. No local files were deleted when preparing this repository.

Virtual environments, Python caches, environment files, macOS metadata and Obsidian state are excluded. The `scratch/` directory preserves exploratory scripts and planning evidence; these are historical working material, not production entry points. Portable handoff snapshots intentionally duplicate source and data to preserve their original bundle manifests.
