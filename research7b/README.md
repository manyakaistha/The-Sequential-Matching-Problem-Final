# Research 7b portable machine handoff

This directory carries the source and evidence needed to **set up and implement** the M4 Mac coordinator branch. It preserves the original research7 plan under `workspace/research7/`. R7 experiment runtime is pending; this package launches no experiments and claims no passed phase tests or improvement.

Copy this entire directory to the target machine, preserving relative paths. Keep the other machine's package separate. Start with [START_HERE.md](START_HERE.md), [BLOCKERS.md](BLOCKERS.md), [OWNERSHIP.md](OWNERSHIP.md) and `workspace/research7/PLAN_7B.md`.

Included: root simulator/interface/baselines/docs, research1–6 source/assets and R6 audits/registrations/reviews/manifests; complete small public dataset splits; original R7 inputs and plans; authoritative R6 stage analysis at original paths; selected older manifests, inventories, designs and analysis. Imports keep their repository-relative paths. Existing `.git`, venvs/caches, huge historical logs and archives are excluded. See [OMISSIONS.json](OMISSIONS.json). Historical reports may contain superseded or overstated interpretations; read R7 EVIDENCE_REVIEW alongside authoritative analysis.

Limits: two later simulation workers by default, one numerical thread each, 10 GiB combined working RSS, 100 GiB new output, 30 GiB free reserve, 160 simulation/test plus 24 fitting CPU-hours; maximum 3 workers globally. These are later execution ceilings, not permission to launch. Inspect real capacity before using them.

`BUNDLE_MANIFEST.json` fingerprints every shipped file except its own checksum pair; `BUNDLE_MANIFEST.sha256` identifies that manifest. It protects original snapshot bytes, not independent scientific correctness or tamper authentication. Preflight verifies listed files, parses Python syntax with AST, and optionally reads hardware/dependency metadata. It never imports policy/simulator modules, invokes Docker, executes phase tests or spawns agents. Future new output files are not included in the original immutable source manifest.

Use Python >=3.10 with stdlib `venv` and Bash for bootstrap (on Windows use WSL/Bash or perform equivalent venv setup manually). Historical research lock was used with Python3.14.7/macOS arm64; validate exact pinned wheel compatibility on this machine. The outer setup lock contains only the historical R6 NumPy/SciPy/NetworkX pins; the complete older tool lock is preserved at `workspace/requirements-research.lock.txt` for optional legacy tooling. Bootstrap is idempotent, retaining existing `.venv`; changed bundled files fail integrity. Repeated setup writes only the current setup report. Full raw archive evidence is an explicit external prerequisite for global freshness and historical independent audits, so these packages alone cannot certify seeds or reconstruct every prior attempt.
