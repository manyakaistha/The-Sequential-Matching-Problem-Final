This is a query-policy hypothesis, not a score-learning or maximum-cardinality claim. N3 matching calls `kit.baseline_match(state)` unchanged. Soft acquisition is disabled. This avoids confounding fewer bundles with smarter allocation. The earlier up-to-four/fewer-query tie proposal is a distinct variant, not silently included.

### Source-conditioned hard sampler

**Source deduction:** a query-eligible missing-hard actor cannot have a prior legal introduction, because every introduction requires all hard fields and hard disclosure is monotone (`kit.py:125–128,149–151`). Therefore N3 need not infer that actor's preference/outcome-history posterior. Hidden hard truth has no influence on busy state for that actor. This removes a major unnecessary inference task. The claim is specific to legal shipped trajectories and must have an independent invariant test.

For each particle and shortlisted actor, sample each missing hard field once; reuse that member realization across **all** incident hypothetical edges and all candidate query batches. Preserve public age/gender/zone, every disclosed value, statuses and public IDs. Samples represent hypothetical answers only for actors in a batch; actors outside it remain publicly incomplete. Hard declines are never queried or imputed as verified.

Implement the actual conditional source law from `kit.py:39–57`, not heuristic dyad compatibility probabilities:

- `age_min=max(18,age-R)` and `age_max=min(65,age+R')`, independent R/R' uniform integers3–10. If a bound is disclosed, preserve its value rather than resample its radius. Respect clipping multiplicities.
- `who_to_meet`: subset size1/2/3 with weights.7/.2/.1; uniform sampled subset of the3 public genders. It is independent of the actor's own gender in the source. Preserve a disclosed full list. No demographic preference inference.
- `relationship_structure`: monogamous.9/non_monogamous.1.
- `smoking`: no.75/occasionally.20/yes.05; `partner_smoking`: no_smoking/any each.5.
- `has_children`: boolean true.15/false.85; `partner_children`: any/no_children each.5; `wants_children`: yes/no/unsure uniform. Never use truthiness as missingness.
- Ordinary `acceptable_zones`: always own zone; extension coin.3 and additional zone chosen **uniformly** from a/b/c/d, deduplicated. Thus singleton-own probability.775 and each particular distinct second zone.075. Do not use the weighted own-zone population distribution for the extension draw. Sparse numeric zone support gives singleton-own with probability1. Public zone support identifies the support branch without a hidden family label. Unsupported zone vocabulary fails to the legal G fallback with recorded reason.
- `schedule`: size1/2/3 uniformly, then uniform subset of weekday_evening/weekend_day/weekend_evening; eligibility uses set intersection. Source list order is irrelevant to legality.

Any missing field rules out the generator's complete-profile branch; the individual missing/declined coins are value-independent in the intended source model. Partial hard-field values are otherwise independent given public age/zone, except each field's internal dependencies above. Own initial completion probability distinguishes ordinary/cold-start missingness, but after observing missing hard fields it does not alter these conditional hard-value laws. These are ideal source-distribution statements; no claim of finite-PRNG statistical independence or unknown real-world validity is made.

### Denominators and labels

- Query support: all pre-ask days; query-eligible days/members; singleton/pair bundles; shared partners; newly verified and newly legal **disjoint** introductions. Separate predicted sampled feasibility from actual revealed feasibility and from actual historical assignment.
- Soft support: operative unseen nondeclined fields on actors with competing alternatives; fields that can change a choice; questions selected; hard bundles displaced. No use of nuisance questions as a new substantive signal.
- Return support: public pending introductions and endpoints; branch-specific known failed/both-first-yes/date-canceled/date-happened/pause cohorts; release windows; availability during action horizon; unused hard-legal partner opportunities and assignments displaced by waiting. Multiple daily predictions for one introduction are repeated forecasts, not independent samples.
- **No-return-by59 is not permanent never-return.** For public labels, return day is the first later day with available=true through59; otherwise label no_return_by59. The latter includes true exit/pause and releases outside the action horizon. Follow-up public pause/date labels may explain parts; unexplained unavailability stays ambiguous. Privileged never-return/busy/exit labels are separate diagnostic tables.
- History support: responding first yes/no versus explicit first no-response; eligible second-stage trials, responding second yes/no versus no-response; current available actors with0/1/2+ trials; legal edges and actual introductions with informative histories. A second event count alone does not establish preference evidence.
- Action support: normalize every pair and compare entire unordered sets; also preserve ordered queries/pairs. Report changed actions against **same-state own parent**, including a no-soft/no-wait/no-gate control, not solely G when scorer/control differs.
