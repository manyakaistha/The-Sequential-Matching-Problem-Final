# Execution interface v1

Director owns orchestrator.py, recorder.py, analysis.py, registry/, decisions.jsonl, and stage grids. Implementers must not edit them. This interface precedes policy implementation and all R6 experiments.

Policy entry: `research6.policies.policy.decide(request, config)` returns exactly `{asks: list, memory: JSON}` or `{pairs: list, memory: JSON}`. `config` is immutable public configuration with candidate `id`. Policies receive only a strict JSON-round-tripped request; no seed, family, simulator or host files. Baseline G must invoke shipped baseline functions unchanged. P must retain round-five population configuration. Algorithm modules expose `action(request, config)` with the same response shape. Proposed modules are allocation.py and acquisition.py; these modules are not yet present. Bounded deterministic work plus an invocation timer and shipped greedy fallback on valid public states are required; malformed requests use an empty legal fallback. Every fallback remains explicitly counted and prevents promotion until resolved.

Host recorder constructs exact JSON bytes, records requests before inference, serialized before/after memory, actions, timings, stderr, predictions where provided, initial/final privileged state separately, and unique attempt IDs. Each invocation uses independently closed gzip chunks. Atomic episode commits follow validation and file hashing. Resume retains all commits including failures and preserves uncommitted attempts. Replay feeds identical recorded request bytes. Simulator horizon remains 60 action days plus 40 advances. Processes max three; one numerical thread each. No B/C/D/E exposure until stage-specific immutable registration and review.

All serious candidates require separate implementation review, high-effort scientific/statistical review and director decision before admission. Deferred learning is allowed only through documented Stage-A evidence and gates, not convenient omission.
