## Prospective prediction-audit source review

Read prediction_audit.py before C completed. It reads only completed C and the
192greedy prospective traces; it refuses absent full match-time states instead
of reconstructing them from terminal disclosures. It verifies state day, prior
intro timestamps, feedback observed-day, arrived actors, profile disclosure dates,
absence of private keys, endpoint availability and exact snapshot/state equality.
Completed future public events are used solely for labels, independently checked
against official qualified totals. No hidden world generation or E access occurs.
Source inspection of the frozen recorder confirms states are copied before
matching. Already-present field values can legally inform earlier acceptance
fit at that invocation; later field values never enter the forecast.

Full-funnel reconstruction is coherent for the **fixed approximate model**:
response uses products of first moments; mutual acceptance adds shared-integrated
joint acceptance; date adds.78; pause uses products of second response moments
and the shared joint four-sigmoid integral; terminal adds.36 and correctly couples
the normal/delayed family contribution. This avoids replacing E[R²] by E[R]²
or breaking reciprocal/cross-stage shared effects. The final terminal expression
is checked to1e−12 against actual frozen scoring functions. Exact response
factorization has its separate approved assumption scope; nuisance priors,
independent trial-regime updates and Gaussian actor-moment matching remain
approximations. This code is an independent public-label/uncertainty audit, not
an independent numerical implementation of forecasts, correctly disclosed.

Loss estimand averages assignment losses within each episode, six family means
within seed, then seeds. Pooled assignment losses and descriptive slices are
separately labeled; zero-assignment episodes trigger an explicit refusal rather
than silently disappearing. Whole-seed t/bootstrap contrast uncertainty and Holm
over four contrasts×two terminal metrics are appropriate for this stated cohort.
Stage/conditional ratio summaries remain descriptive. Same-model ratio forecasts
are coherent conditional probabilities under its approximate model, not products
of separately calibrated regressions. Sparse/all-zero reliability bins have
unavailable intervals and cross markers. No AUC or favorable proper-score point
estimate is allowed to establish policy superiority.

No blocking forecast/timing/label error found. Actual C output must still satisfy
these assertions before claims are made. The calibration cohort assesses forecasts
on shipped greedy assignments, not action coverage or off-policy reward value.
The audit's four forecast contrasts differ deliberately from the four policy
mechanism contrasts; distinguish both families in reporting.
