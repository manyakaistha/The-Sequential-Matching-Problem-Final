## Deterministic semantic-action theorem

For any shipped world and any of the eight frozen round-four candidate configs,
change only second-feedback delays to other integers1–5, preserving response
flags, yes/no values, date day/cancellation, introduction-stage events, exogenous
arrivals/exits and hard/soft truth. Preserve explicit no-response observation at
date+5. Recompute a positive-pause timestamp as the maximum changed responding
second-feedback timestamp. Busy release remains date+6. Then the **normal inner
decision path** generates exactly the same ordered asks/pairs at every action
day; hence introduction IDs, assignment days and all nonintervened stage draws
are unchanged. This is not a theorem about a policy timing out or crossing a
request-size guard: resource failures can change an executable's response, so
the guarded executable conclusion additionally requires no fallback/size failure.

Proof by induction over invocations. Starting profiles and availability coincide.
Changing second timing cannot change availability: busy release is date+6,
later than any changed response or positive-pause time. Before release, an
endpoint is unavailable regardless of pause; by release a positive pause has
already been observed under either timing. Nonpositive endpoints release at
the same day. Exits/arrivals likewise coincide.

All query modes depend on currently available profile fields, verified/nonrepeat
edges and (for hard priority) public profile demographics/partial feasibility;
none uses second-feedback timestamps or global feedback totals. Thus asks and
resulting profile disclosures coincide. Greedy and population matchers use those
same profiles/availability and the same previous dyads. Beta/Uniform matchers
only use response counts for legal-edge endpoints. An available endpoint has
all its prior incident events received under both timings before date+6, so
these counts coincide. The acceptance posterior uses **introduction responses**,
current disclosed fields and assignment days, all unchanged; second timings
are not an input. Although its code computes posteriors for unavailable actors,
the scored edges use only currently available endpoints and those unchanged
posteriors. No config learns a global parameter from partial second feedback.
Therefore every edge weight, canonical tie and sorted disjoint allocation
coincides. The source keys each later outcome stream by dyad/day, so induction
preserves its nonintervened outcomes. ∎

This is a source-specific strengthening of the prior positive-pause reward
identity/information-timing observation, not a broad novelty claim. A policy
that updates global parameters using newly received seconds, queries based on
pending global labels, or counts pooled feedback to switch phases need not be
invariant. Releasing at date+2 or making pause effective beyond date+6 would
also invalidate this proof. It does not show invariance to date delays, whose
busy release and date qualification can alter later opportunities.

## Conditional reward identity under stochastic assumptions

Under the intended independent fresh-draw interpretation, the two responding
second-feedback delays are uniform1–5 and independent of their yes/no/submission
flags. Here **delay-erased trajectory** means the sigma-field generated by all
non-second-feedback-delay primitives: profile/disclosure/arrival/exit variables,
response and yes/no flags, introduction response delays, date lags/cancellations,
and independent policy randomness. The semantic-action theorem makes actions,
assignments and K measurable with respect to this sigma-field. It does **not**
mean deleting timestamps from the full observation history while retaining
event presence/absence at day invocations: that latter record still reveals
second delays and would not support the conditional .36 calculation.
Define K as the number of both-positive second pairs whose date satisfies
`date−assignment <=30`, across the full action/follow-up trajectory. The theorem
means changing feedback delays cannot change its future actions or K. Conditional
on that delay-erased trajectory, each of these K introductions qualifies with
probability `(3/5)^2=.36`. If N members have arrived, then

`E[qualified MSMI/100 | delay-erased trajectory] = 100*.36*K/N`.

At N=200, this is `.18*K`, equivalently `.36*K/2`. This diagnostic integrates
only feedback deadlines, not date qualification or cancellations, actor responses,
acceptance, second preferences or occupancy. With independent introduction
feedback delays the conditional variance of the unscaled count is
`K*.36*.64`; conditional covariances between policies can differ when they share
the same dyad/day streams. The identity's unbiasedness does not require treating
assignment-level observations as independent policy-reward samples.

This stochastic conditional-expectation identity is separate from deterministic
PRNG replay: one finite seed's reward need not equal its expectation, and the
finite keyed generator does not prove independent streams. It also does not
replace the registered primary metric after seeing results. The integrated
proxy is a transparent exploratory mechanism/noise diagnostic; it can motivate
a future prospectively registered variance-reduction endpoint, subject to the
same invariance assumptions and a separate analysis plan.

The exact .36 identity applies to the abstract inner decision. Extending it to
the guarded executable requires the normal path for **every** feedback-delay
assignment relevant to the fixed non-delay primitives, not merely zero fallbacks
on the realized trajectory. Conditioning on observed no-fallback could itself
select delay-dependent request sizes or latencies. The finite tests below do not
prove counterfactual resource success for all such assignments. Accordingly the
proxy is not claimed as an exact unconditional guarded-executable value estimator.

## Intervention audit contract

The diagnostic subclass mutates only newly scheduled responding second timestamps
to date+1 versus date+5 and moves the corresponding positive-pause timestamp.
It does not add/remove any draw, modify source, alter busy release or recompute
yes/no/cancellation/response flags. Explicit second no-response events remain
at date+5. Both extreme-delay variants run60 action days plus40 empty follow-up
with public JSON requests. Required comparisons: ordered action equality,
availability equality, introductions equality, zero fallbacks, same K, fast
qualified count=K, slow qualified count=0. These artificial rewards are
**not deployable policy evaluations** and cannot be reported as beating greedy.

The completed-trace calculation independently rebuilds dates, seconds and
positive pauses, checks stage flags agree with pause events, matches original
qualified counts and score denominators, then computes actual score, integrated
proxy and actual−proxy. Six correlated families are averaged per seed before
paired comparisons. Baseline and available own-architecture contrasts are all
reported descriptively with seed-cluster intervals; no searched positive proxy
comparison becomes confirmatory superiority.

Exact command and measured results will be recorded after execution; no finite
replay can prove the universal source claim, but a mismatch can falsify it.
