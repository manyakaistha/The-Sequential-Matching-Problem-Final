# Runtime blockers

This package is a setup and implementation handoff. No R7 runner, registry, seed certification, recorder, merger, independent exact solver, phase tests or candidate models have been implemented or executed by packaging. Future CLI strings in the original plan are specifications. There is no runnable research launch script.

1. Implement and independently review P0/P1 infrastructure, observation/metric semantics and safe merge interfaces under concrete file ownership.
2. Supply all historical raw seed-use and reservation evidence, including external-machine declarations and archived/interrupted attempts, to the coordinator. The bundled historical inventories do not certify R7 seeds. Obtain a reviewed freshness audit and immutable registration before any world generation.
3. Resolve actual machine Python/wheel compatibility for the pinned lock (historical environment was Python 3.14.7 on arm64 macOS), provider capabilities, model IDs and live reviewer identities. Lock copy is not a compatibility guarantee for another OS/Python.
4. Freeze actual policy/code/assets/dependency fingerprints and complete grid/leases/resource forecasts. Candidate models and shared registries are future outputs.
5. Preserve current no-experiments boundary. A later explicit execution task and reviewed registration are needed for simulator calls, exact-model runs, synthetic phase tests, training, benchmarks, or confirmation. Static AST/integrity/hardware/dependency metadata checks here are not phase-test evidence.

Default bootstrap only creates an isolated environment and inspects metadata. Optional dependency installation contacts the package index; it does not contact model providers. Docker executable presence does not verify restricted-container support.
