This differs from immediate cardinality acquisition, permanent actor prices, and single-edge throughput. Implementing a bigger static ranker or another N3 particle count is not that mechanism. Greedy remains the supported default.

## Legal belief-state objective

Let H_t be public observation/history and policy memory before asking, including actual fields/statuses, observed events, availability and past dyads. Let b_t be a specified posterior over persistent actor parameters, missing attributes, regime and pending states, conditioned only on H_t. Unarrived members' identities/profiles and true exits are not observed. Ask A is a nonadaptive batch with total cost at most 12; constraints cost 3, soft fields 1. Only available actors can be queried. A permanent hard decline excludes introduction. Let Y_A denote the joint answers, O_t^+ the refreshed observation, and M a legal matching of actual fully verified, available, unused dyads.

With expected eventual rewards booked once at assignment,

    V_t(H) = max_A E_Y[ max_M { sum_(e in M) q_e(H,Y)
                                  + E[V_(t+1)(H') | H,Y,M] } ],
    V_60 = 0.

This is a finite-horizon partially observed control definition, not an executable exact solution. q is conditional probability of qualified MSMI, not acceptance, date, pause or a shipped soft score. Booking expected eventual reward is legitimate by linearity/iterated expectation with full follow-up; pending outcomes remain in the transition and information model but are not rewarded twice. Separate q from pause probability p and the full return distribution. No independence between reward, occupancy, feedback and posterior update is implied.

The continuation gain is a **joint action** quantity:

    Advantage(M,M0 | H) = sum_e q_e(M)-sum_e q_e(M0)
                         + E[V(H'_M)-V(H'_(M0)) | H].

The future usable graph removes past dyads, changes availability and hard knowledge, loses paused/exited actors and adds public-model arrivals. A policy cannot replace this with a fabricated known future schedule.

For a fixed deployable post-answer controller C, query action value is instead

    Q_C(A|H) = E_Y[ Q_match(H,Y,C(H,Y)) ].

Use the controller actually deployed. Computing an optimal matching after hypothetical answers but executing greedy measures a different policy. Optimize complete cost-feasible batches; single-query value/cost misses complements. Unspent budget has no carryover. Primary reward contains no direct query-cost subtraction: displacement of useful questions belongs in the feasible batch optimization; ask cost is a secondary metric. A scalar budget price is an explicitly approximate alternative.

## Why static prices and cardinality need falsifiers

**Proved algebraic invariance.** For matching score sum_(ij in M)(w_ij-lambda_i-lambda_j), if two alternatives cover exactly the same endpoint set S, the price subtraction is the common constant sum_(i in S)lambda_i. Static node prices cannot distinguish these matchings. Likewise a global cardinality bonus is constant among same-cardinality alternatives. Prices may change *which actors* are used or whether to wait; the statement does not refute all adaptive/edge/time-specific prices.

**Inherited nonseparability witness.** Future AC yields 9/10 only when both survive. Current AB and CD each reward 1/2 and certainly retire. Taking both yields 1; wait yields 9/10. Charging each assignment its standalone 9/10 future loss rejects both, double-counting one shared alternative. Endpoint-additive continuation is not exact; a joint residual or state transition is necessary in this witness.

**No broad information monotonicity for heuristics.** Exact optimal value cannot fall when extra information can be ignored at no resource/opportunity cost. Greedy or misspecified controllers need not ignore it and can worsen. More accurate posterior estimation, more verified edges or more matches therefore supplies no policy-improvement theorem here.
