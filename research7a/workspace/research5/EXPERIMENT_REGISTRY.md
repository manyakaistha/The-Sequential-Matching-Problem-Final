## Hypothesis and unchanged policy

Population_control (round-four frozen match=population, ask=fifo) has a positive
mean qualified MSMI/100 effect over shipped kit.baseline_asks/baseline_match in

## Sample and power

5160 episodes. Proposed seeds must not intersect recorded actual/planned/reserved
prior seeds, including all round-four reserved ranges and guard1–10000. Inventory
scope is repository evidence, not a guarantee against unrecorded external use.
No proposed world is generated by inventory/power checks.

Planning effect +.05 MSMI/100; conservative seed-difference SD .26, above the
observed round-four C .252618 and E .227585. Model power is the positive-tail
rejection probability for a paired t statistic with noncentrality delta*sqrt(n)/SD
and two-sided critical value t(1-alpha/2,n-1). At alpha .0125, minimum n390 yields
90% model-based power; 10% inflation produces fixed n430 (about93% modeled power).
Normal-cluster assumptions make this an exact power calculation for that model,
not a guarantee for the nonnormal simulator distribution. SD/effect sensitivity
is retained. No blinded or outcome-driven sample reassessment or extension.

This powers detection of a positive effect against zero when truth is +.05.
It does NOT power proving an effect above +.05 when truth is exactly +.05.

## Full logging amendment (before execution)

Every invocation records the complete policy-visible request (including all
observations and incoming memory), returned response (including outgoing memory),
sequence, command, configured timeout, UTC timestamps and elapsed inference time.
Requests are flushed before inference; responses/errors are flushed immediately
afterwards. Invocation and episode exceptions include traceback diagnostics.
Policy-call timing excludes the added log writes, but host I/O/load can still
affect timing. Primary execution remains in-process JSON, with no child stdout
or stderr stream; this recorder refuses subprocess mode. Independent subprocess
replays remain a separate required check.

Separate privileged gzip files retain the initial generated world (including
latent member parameters) and complete final simulator attributes, including all
scheduled events. These files are audit-only, never policy inputs or model fitting
data. Internal machine instructions and individual RNG calls are not separately
traced; immutable simulator source and initial world permit reconstruction.
Each closed gzip file has SHA256 and byte size in its episode row. Original
prospective traces and console/execution logs remain. Abrupt process/host death
can leave an incomplete gzip member; flushed records may be salvaged, but no
crash-proof durability or completed-test claim is made.

Valid JSON inputs/outputs are preserved completely. Invalid Python return objects
are captured as diagnostic JSON text or safe repr text, including a fallback for
cyclic/unrepresentable objects; that diagnostic representation is approximate,
not a reversible serialization of arbitrary Python objects.
