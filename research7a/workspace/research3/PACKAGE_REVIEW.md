## Pre-final observed evidence

The final report generator reads registered screen/focus/selection/confirmation
statistics and chooses its conclusion from the paired confidence interval. It
states nonsignificance is not equivalence, distinguishes the practical +.10 target,
and does not promote searched exploratory ranks to confirmation. Per-family
results remain descriptive. The analyzer uses the seed as cluster, averaging all
six families before paired differences; duplicated, incomplete, failing/fallback
or nonpaired grids are rejected. Every retained episode has its own raw resource
measurements, and reward inference never uses independent assignment-level errors.

The report repeats the established old negative result and qualifies oracle and
trajectory mechanisms. Its old funnel counts match the independently recomputed
forensic record; cancellation and qualification denominators remain distinct.
It separates scoped mathematical results, exact public calculations, tiny-model
DP, empirical findings, approximations and unvalidated hypotheses. It warns that
returned empty memory does not erase public request histories, and finite stress
cases do not imply arbitrary-input timeout guarantees. Current container image
size is Docker inspect Size, with the actual documented 2 GiB bound.

Prospective benchmark snapshots contain a auxiliary inherited integrated-prior `prediction`,
not every candidate's score or the new six-family population-mixture forecast. The report's matched-cohort prediction framing is
appropriate; these predictions must continue to be identified as diagnostics in
any downstream calibration analysis. No confirmation data are fit or used for
selection in the registered stage driver. Source/config and registry digests are
frozen before confirmation; a fixed sample rule uses development-cluster SD with
floor/cap and explicitly notes its power approximation.

Historical preservation is checked against the start-of-round inherited manifest.
This verifies bytes actually present at start, not an invented claim those bytes
matched every old freeze. Report correctly distinguishes recovered old frozen
files from inherited modified root sources. Inference packaging copies only the
five permitted source files, and actual image/host source hashes agree.

## Archive and restoration review

The archive records repository-relative member paths, byte counts and SHA256 and
checks compressed archive hashes. Verification rejects unexpected/duplicate/
nonregular members, unsafe absolute/parent paths and differing existing file bytes.
Missing originals are recreated with exclusive creation; existing originals are
not overwritten. This is lossless consistency evidence, not a historical trusted
timestamp. Archive verification can operate without raw files; reanalysis requiring
traces needs restoration. Build refuses archive overwrite but index writing itself
can replace an index; the intended single final build must be preserved. No old
archives are modified. Archive payload is read per member, so offline verification
RAM scales with the largest trace rather than streaming every member byte; policy
inference restrictions do not apply to this separate offline operation.
